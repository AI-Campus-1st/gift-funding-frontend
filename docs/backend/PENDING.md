## 4. 알아 둘 점 (결정 필요 없음)

- **DB로 막지 못하고 서버가 막는 규칙**: 펀딩은 그 그룹을 만든 사람만 연다(`fundings.owner_id = groups.admin_id`), 시작일은 오늘 이후, 연결 펀딩 열람 권한 — 다른 테이블 값이나 오늘 날짜가 필요해서 DB CHECK로 걸 수 없다.
- **Mock 테스트 데이터와 DB 테스트 데이터의 차이**: DB는 펀딩 기간 최대 21일 규칙(CHECK) 때문에 일부 펀딩 기간을 Mock보다 짧게 넣었다. 계정 · 그룹 · 금액은 같다.
- **테스트 데이터 날짜**: `02_data.sql`의 날짜는 DB를 **만든 날** 기준이다. 날이 지나면 "오늘 생일" · "진행 중" 펀딩이 하루씩 밀린다 → 처음 상태로 보려면 `docker compose down -v && docker compose up -d --build`
- **로그인 전 화면의 `401 /me`**: 로그인 화면 · 회원가입 화면에서 "이미 로그인했는지" 확인하는 요청이라 정상이다.
- **백엔드 테스트**는 DB 테스트 데이터(`02_data.sql`)가 들어간 DB에서 돈다: `docker compose exec backend pytest`. 테스트가 바꾼 데이터는 끝나면 되돌린다.
