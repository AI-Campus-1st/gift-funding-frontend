### UI-04 홈 페이지 화면명세서

### 1. 화면 개요

- **화면 ID:** UI-04
- **화면 이름:** 홈 페이지
- **화면 목적:** 로그인한 사용자가 자신의 생일, 진행 중인 펀딩, 참여 중인 친구 펀딩과 생일 일정을 한 화면에서 확인하고 주요 기능으로 이동하도록 한다.
- **접근 권한:** 로그인 사용자
- **관련 기능 ID:** F-01 회원가입 및 로그인, F-06 초대 링크 및 친구 펀딩 참여, F-07 생일 펀딩 생성 및 관리, F-09 모금 현황 및 달성률 관리, F-13 후원 정보 공개 및 비공개 처리, F-15 생일 캘린더, F-16 알림 기능
- **파일명:** `04_home.md`
- **화면 경로:** `/home` (제안 경로; 라우팅 구현 시 확정)

#### 1.1 기본 정책

- 로그인에 성공한 사용자의 기본 진입 화면이다. 단, 초대 링크를 통해 로그인한 경우에는 초대 참여 과정을 우선 이어간다.
- 한 사용자는 자신의 펀딩 생성자이면서 다른 펀딩의 후원자가 될 수 있다.
- **내 펀딩** 정보에는 실제 전체 모금액과 달성률을 표시할 수 있다.
- **친구 펀딩** 정보에는 달성률(%)과 진행률 바를 표시하며, 실제 전체 모금액·남은 모금액·다른 후원자의 후원 금액은 노출하지 않는다.
- 펀딩 정보는 해당 사용자가 접근 권한을 가진 항목만 조회한다.
- 홈 본문에는 그룹 요약 카드와 최근 알림 목록을 표시하지 않는다. 그룹은 하단 `그룹` 탭에서 확인한다.
- 알림은 상단 헤더의 알림 버튼으로만 접근한다. 읽지 않은 알림이 1건 이상이면 아이콘 오른쪽 위에 빨간색 원형 표시를 노출한다.
- 홈 화면은 요약 정보와 바로가기를 제공하며, 상세 조회 및 수정은 각 전용 화면에서 수행한다.

### 2. 화면 구성 및 배치

#### 2.1 상단 영역

**표시 요소**
- 레트로 창 스타일의 공통 헤더
- 서비스 로고 또는 `홈` 제목
- 알림 버튼(종 모양 아이콘) 및 읽지 않은 알림이 있을 때만 나타나는 빨간색 동그라미
- 사용자 이름을 포함한 환영 문구
- 내 생일 날짜 및 D-day

**버튼 이름**
- `알림`

**배치 위치**
- 화면 최상단에 공통 헤더를 배치한다.
- 알림 아이콘은 헤더 오른쪽에 배치한다.
- 환영 문구와 생일 정보는 헤더 아래에 카드 형태로 배치한다.

**버튼 동작**
- `알림` 클릭 시 알림 목록 화면(UI-29)으로 이동한다.
- 읽지 않은 알림이 1건 이상이면 알림 아이콘 오른쪽 위에 작은 빨간색 원형 점을 표시한다.
- 읽지 않은 알림이 0건이면 빨간색 점을 숨긴다. 점에는 숫자를 표시하지 않는다.
- 알림 내용이나 최근 알림 목록은 홈 본문에 표시하지 않는다.

**표시 예시**
- `서연님, 반가워요! 🎂`
- `내 생일: 11월 12일`
- `생일까지 D-28`

**데이터 표시 내용**

| 항목 | 데이터 | 표시 규칙 |
|---|---|---|
| 사용자 이름 | 로그인 사용자 프로필 이름 | 이름을 포함한 환영 문구 |
| 생일 | 사용자 프로필의 생년월일 | 월·일 중심으로 표시 |
| D-day | 현재 날짜와 다음 생일 사이의 날짜 차이 | 생일 당일은 D-day, 이전은 D-N 형태 |
| 읽지 않은 알림 | 현재 사용자의 미확인 알림 수 | 1건 이상이면 빨간색 점 표시, 0건이면 점 숨김 |

#### 2.2 중앙 영역

**표시 요소**
1. 내 진행 중 펀딩 요약
2. 내 펀딩 만들기 바로가기
3. 참여 중인 친구 펀딩 요약
4. 친구 펀딩 참여하기 바로가기
5. 생일 캘린더 미리보기

**컴포넌트 배치**
- 각 영역을 세로로 배치한다.
- 요약 정보는 레트로 창 스타일의 카드로 구분한다.
- 각 영역 제목 옆 또는 하단에 `전체 보기` 링크를 배치한다.
- 모바일 화면에서 카드가 잘리지 않도록 화면 너비에 맞춘다.

##### 2.2.1 내 펀딩 요약 영역

**표시 요소**
- 섹션 제목: `내 펀딩`
- 진행 중인 펀딩 요약 카드
- 펀딩 이름, 연결된 그룹, 종료일, 진행 상태
- **내 펀딩의 실제 전체 모금액 및 달성률**
- `펀딩 만들기`, `전체 보기` 버튼

**동작**
- 펀딩 카드를 클릭하면 내 펀딩 상세 및 관리 화면(UI-12)으로 이동한다.
- `펀딩 만들기` 클릭 시 펀딩 생성 화면(UI-09)으로 이동한다.
- `전체 보기` 클릭 시 내 펀딩 화면(UI-05)으로 이동한다.

**빈 목록 처리**
- 진행 중인 펀딩이 없으면 `아직 진행 중인 펀딩이 없어요.` 안내를 표시한다.
- `펀딩 만들기` 버튼은 계속 표시한다.

##### 2.2.2 친구 펀딩 요약 영역

**표시 요소**
- 섹션 제목: `친구 펀딩`
- 참여 중인 친구 펀딩 카드
- 생일자 이름, 펀딩 이름, 종료일, 진행 상태
- 선물별 또는 펀딩 요약 달성률(%) 및 진행률 바 (구체적인 집계 단위는 데이터 설계 시 확정)
- `+ 친구 펀딩 참여하기`, `전체 보기` 버튼

**정보 공개 규칙**
- 실제 전체 모금액과 남은 모금액을 표시하지 않는다.
- 다른 후원자의 이름, 개별 후원 금액 및 내역을 표시하지 않는다.
- 사용자 본인의 후원 내역은 별도 내역 화면에서 확인한다.

**동작**
- 친구 펀딩 카드 클릭 시 친구 펀딩 상세 화면(UI-18)으로 이동한다.
- `+ 친구 펀딩 참여하기` 클릭 시 초대 링크 입력 모달 또는 참여 절차를 연다.
- `전체 보기` 클릭 시 친구 펀딩 화면(UI-07)으로 이동한다.

**빈 목록 처리**
- 참여 중인 펀딩이 없으면 `아직 참여한 친구 펀딩이 없어요.`를 표시한다.
- `+ 친구 펀딩 참여하기` 버튼을 제공한다.

##### 2.2.3 생일 캘린더 미리보기

**표시 요소**
- 섹션 제목: `생일 캘린더`
- 등록된 생일 일정의 미리보기
- 날짜와 대상 사용자 이름
- `전체 보기` 버튼

**동작**
- `전체 보기` 클릭 시 생일 캘린더 화면(UI-28)으로 이동한다.
- 접근 가능한 생일 일정만 표시한다.

**빈 목록 처리**
- 표시할 일정이 없으면 `등록된 생일 일정이 없어요.`를 표시한다.

#### 2.3 하단 영역

**표시 요소**
- 로그인 사용자용 공통 하단 5개 탭 메뉴

**버튼 이름 및 이동 대상**

| 탭 이름 | 이동 화면 | 홈에서의 상태 |
|---|---|---|
| 홈 | UI-04 홈 | 활성 |
| 내 펀딩 | UI-05 내 펀딩 | 비활성 |
| 그룹 | UI-06 그룹 | 비활성 |
| 친구 펀딩 | UI-07 친구 펀딩 | 비활성 |
| 마이페이지 | UI-08 마이페이지 | 비활성 |

**배치 위치 및 고정 여부**
- 화면 하단에 공통 내비게이션을 배치한다.
- 콘텐츠가 길어질 때에도 하단 메뉴에 접근할 수 있도록 고정형으로 구현한다.
- 하단 메뉴 높이만큼 본문에 여유 공간을 확보하여 마지막 카드가 가려지지 않게 한다.

### 3. UI 컴포넌트 상세

#### 3.1 공통 헤더 (`home-header`)
- **UI 형태:** 레트로 창 제목 표시줄
- **표시 문구:** `홈` 또는 서비스 로고
- **포함 요소:** 종 모양 알림 버튼, 읽지 않은 알림이 있을 때 표시되는 빨간색 원형 점
- **점 위치:** 알림 아이콘 오른쪽 상단(아이콘에 겹쳐 보이도록 배치)
- **점 스타일:** 빨간색(` #EF4444 `), 지름 약 8px, 원형, 숫자 없음
- **표시 조건:** 읽지 않은 알림 1건 이상이면 표시, 0건이면 숨김
- **클릭 동작:** 알림 버튼 클릭 시 UI-29 알림 목록 이동
- **접근성:** 버튼에 `알림` 접근성 이름을 제공하고 읽지 않은 알림이 있으면 상태를 보조기기에 전달

#### 3.2 생일 및 환영 카드 (`birthday-summary-card`)
- **UI 형태:** 정보 카드
- **표시 내용:** 사용자 이름, 생일, D-day
- **기본값:** 로그인 사용자 프로필 기반
- **예외:** 생일 정보 조회 실패 시 오류 안내 및 재시도 제공

#### 3.3 내 펀딩 카드 (`my-funding-card`)
- **UI 형태:** 펀딩 요약 카드
- **표시 내용:** 펀딩 이름, 그룹, 기간, 상태, 실제 전체 모금액, 달성률
- **클릭 동작:** UI-12 이동
- **권한:** 해당 펀딩의 생성자에게만 실제 모금액 표시

#### 3.4 친구 펀딩 카드 (`friend-funding-card`)
- **UI 형태:** 펀딩 요약 카드
- **표시 내용:** 생일자, 펀딩 이름, 상태, 달성률, 진행률 바
- **클릭 동작:** UI-18 이동
- **제외 정보:** 실제 모금액, 남은 모금액, 타인의 후원 내역

#### 3.5 빠른 실행 버튼 (`quick-action-buttons`)
- **버튼:** `펀딩 만들기`, `+ 친구 펀딩 참여하기`
- **클릭 동작:** 각각 UI-09 이동 / 초대 링크 입력 절차 실행
- **상태:** 처리 중에는 중복 클릭을 방지한다.

#### 3.6 생일 캘린더 미리보기 (`birthday-calendar-preview`)
- **UI 형태:** 일정 미리보기 카드
- **표시 내용:** 등록된 생일 날짜와 대상자
- **클릭 동작:** `전체 보기`로 UI-28 이동

#### 3.7 하단 내비게이션 (`bottom-navigation`)
- **UI 형태:** 아이콘 및 텍스트를 포함한 5개 탭
- **기본 상태:** 홈 탭 활성
- **클릭 동작:** 각 메인 메뉴로 이동

### 4. 사용자 동작 및 처리 흐름

#### 4.1 일반 로그인 후 홈 진입
1. 사용자가 로그인에 성공한다.
2. 서버에서 인증된 사용자 정보를 확인한다.
3. 홈에 필요한 생일, 내 펀딩, 친구 펀딩, 생일 일정 및 읽지 않은 알림 여부를 조회한다.
4. 사용자 권한에 따라 조회 및 표시할 데이터를 구분한다.
5. 홈 화면을 표시한다.

#### 4.2 내 펀딩 확인
1. 사용자가 `내 펀딩` 요약 카드를 확인한다.
2. 해당 카드에서 실제 전체 모금액 및 달성률을 확인한다.
3. 카드를 선택하면 내 펀딩 상세 화면으로 이동한다.

#### 4.3 친구 펀딩 참여
1. 사용자가 `+ 친구 펀딩 참여하기`를 클릭한다.
2. 초대 링크 입력 모달 또는 참여 화면을 표시한다.
3. 초대 링크 유효성 및 접근 권한을 검증한다.
4. 유효하면 참여 확인 화면으로 연결한다.
5. 참여 완료 후 친구 펀딩 상세 화면으로 이동한다.

#### 4.4 생일 캘린더 확인
1. 사용자가 생일 캘린더 미리보기를 확인한다.
2. `전체 보기`를 선택하면 UI-28 생일 캘린더로 이동한다.

#### 4.5 알림 확인
1. 읽지 않은 알림이 있으면 상단 알림 버튼 오른쪽 위에 빨간색 점이 나타난다.
2. 사용자가 상단 알림 버튼을 누르면 UI-29 알림 목록으로 이동한다.
3. 알림을 읽어 읽지 않은 알림이 0건이 되면 홈의 빨간색 점이 사라진다.

### 5. 데이터 조회 및 표시 규칙

| 데이터 | 조회 기준 | 표시 범위 |
|---|---|---|
| 사용자 이름·생일 | 로그인 사용자 | 본인 정보 |
| 내 펀딩 | 생성자 ID = 로그인 사용자 | 실제 모금액·달성률 포함 |
| 친구 펀딩 | 사용자가 참여 권한을 가진 펀딩 | 달성률·진행률만 표시 |
| 생일 일정 | 사용자에게 허용된 캘린더 일정 | 날짜 및 대상 정보 |
| 알림 | 로그인 사용자 수신 알림 | 홈에서는 읽지 않은 알림 유무만 점으로 표시; 내용은 UI-29에서 확인 |

- 친구 펀딩에 대한 금액 비공개 규칙은 화면 숨김뿐 아니라 서버 응답 권한 검증에도 적용한다.
- 펀딩이 종료되거나 목표 달성 상태가 변경되면 최신 상태를 반영한다.
- 카드 표시 개수와 미리보기 정렬 기준은 기존 기획서에 고정된 수치가 없어 구현 시 확정한다.

### 6. 화면 상태 정의

| 상태 | 표시 내용 | 처리 방식 |
|---|---|---|
| 초기 진입 | 홈 화면 진입 준비 | 인증 상태 확인 |
| 로딩 | 카드 또는 스켈레톤 로딩 | 조회 완료 후 데이터 표시 |
| 정상 | 조회된 요약 카드 및 바로가기 | 일반 상호작용 허용 |
| 데이터 없음 | 영역별 빈 목록 안내 | 생성·참여 버튼 제공 |
| 부분 조회 실패 | 실패한 영역에 오류 문구 | 다른 정상 영역은 유지, 재시도 제공 |
| 인증 만료 | 재로그인 안내 | UI-03 로그인으로 이동 |
| 접근 권한 없음 | 비공개 정보 차단 | 허용되지 않은 데이터 표시 금지 |

---

### 7. 예외 처리

| 상황 | 안내 또는 처리 |
|---|---|
| 로그인하지 않은 사용자가 홈에 접근 | 로그인 화면(UI-03)으로 이동 |
| 인증이 만료됨 | 재로그인 안내 후 UI-03 이동 |
| 프로필 정보 조회 실패 | 생일 카드 오류 표시 및 재시도 |
| 내 펀딩이 없음 | 빈 상태 안내와 `펀딩 만들기` 제공 |
| 친구 펀딩이 없음 | 빈 상태 안내와 `+ 친구 펀딩 참여하기` 제공 |
| 캘린더 일정이 없음 | 캘린더 영역에 빈 상태 안내 |
| 읽지 않은 알림이 없음 | 헤더의 빨간색 점 숨김 |
| 알림 상태 조회 실패 | 빨간색 점을 임의로 표시하지 않고 알림 버튼은 유지 |
| 초대 링크가 유효하지 않음 | 유효하지 않거나 만료된 링크 안내 |
| 조회 권한이 없는 펀딩 | 상세 정보 노출 없이 접근 차단 |
| 네트워크 오류 | 오류 안내 및 재시도 제공 |

### 10. 구현 시 확인 사항

1. 홈의 펀딩 요약 카드 표시 개수와 정렬 순서를 확정한다.
2. 친구 펀딩 요약 달성률의 집계 단위(선물별 또는 펀딩 전체 요약)를 확정한다.
3. D-day 계산에서 윤년 생일(2월 29일) 처리 정책을 확정한다.
4. 생일 캘린더 미리보기 표시 건수를 확정한다. 알림은 홈에 목록으로 표시하지 않는다.
5. 초대 링크 입력은 별도 페이지가 아닌 모달로 구현할지 확정한다.
6. 실제 결제·정산을 도입하지 않는 MVP라면 모의 후원 데이터가 실제 입금액처럼 오인되지 않도록 표기한다.
7. UI-09 이후의 화면 ID는 개별 화면명세서 작성을 위해 제안한 번호이므로 최종 화면 목록과 함께 확정한다.
