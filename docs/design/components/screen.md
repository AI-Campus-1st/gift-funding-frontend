
# AI 기반 생일선물 공동 펀딩 플랫폼 — 공통 화면 설계 기준 (screen.md)

**문서 목적:** 화면 공통 구성, 화면명세서 위치, UI ID, 화면 이동 및 권한별 노출 범위를 정의한다. 각 화면의 상세 UI와 동작은 `docs/design/pages/01_auth.md`부터 `10_others.md`까지의 개별 통합 화면명세서를 우선 확인한다.

**참조 문서**
- 기능 및 비즈니스 규칙: `docs/product/FEATURE_SPEC.md`
- 서비스 정의: `docs/product/DEFINITION.md`
- 디자인 시스템: `docs/design/components/base.md`
- 화면별 상세 명세: `docs/design/pages/*.md`

> 모든 경로는 프로젝트 루트 `gift-funding/` 기준이다. 이 문서는 화면별 상세 명세를 대체하지 않으며, 세부 규칙은 해당 파일을 확인한다.

## 1. 공통 화면 구성

### 1.1 공통 헤더
- 서비스 로고 또는 현재 화면 제목을 표시한다.
- 세부 화면에서는 필요한 경우 뒤로 가기 버튼을 제공한다.
- 홈 화면 상단에는 알림 버튼을 배치한다.
- 읽지 않은 알림이 1건 이상일 때 알림 아이콘 오른쪽 위에 **숫자 없는 빨간색 원형 점**을 표시한다.
- 알림 목록은 별도 UI-29에서 확인하며 홈 본문에 최근 알림 목록을 표시하지 않는다.

### 1.2 공통 내비게이션
- 로그인 후 하단 주요 탭: **홈 / 내 펀딩 / 그룹 / 친구 펀딩 / 마이페이지**.
- 랜딩·회원가입·로그인에는 로그인 후 내비게이션을 표시하지 않는다.
- 홈 본문에는 그룹 요약 카드를 표시하지 않는다. 그룹은 하단 **그룹** 탭에서 접근한다.
- 생일 캘린더는 홈 미리보기 또는 마이페이지 등의 정의된 진입 경로를 통해 접근한다.
- 세부 화면의 하단 탭 노출 여부는 해당 화면명세서를 따른다.

### 1.3 공통 UI 컴포넌트
- 버튼, 입력창, 날짜 선택창, 이미지 업로드 영역
- 선물 카드, 펀딩 카드, 그룹 카드, 진행률 바, 상태 표시
- 후원 금액 추천 버튼과 직접 입력창(연한 회색 Placeholder: `직접 입력하기`)
- 축하 메시지 입력 및 추천 문구
- 초대 링크 입력·복사, 확인 모달, 오류·성공 안내
- 삭제 확인 모달(`delete-confirm-dialog`): 펀딩 · 선물 삭제 공통 (`정말 삭제하시겠습니까?` / `취소` · `삭제`)
- 로딩, 빈 목록, 권한 없음, 입력 오류, 완료 상태

## 4. 권한별 정보 표시 기준

| 화면 정보 | 생일자(본인 펀딩) | 후원자(친구 펀딩) |
|---|---|---|
| 선물 이름·이미지 | 표시 | 표시 |
| 상품 구매 링크 | 표시 | 표시 |
| 선물 가격·목표 금액 | 표시 | 표시 |
| 선물별 현재 전체 모금액 | 표시 | **비공개** |
| 남은 모금액 | 표시 | **비공개** |
| 목표 달성률(%) | 표시 | 표시 |
| 진행률 바 | 표시 | 표시 |
| 본인 후원 금액·내역 | 해당 시 표시 | 표시 |
| 다른 후원자의 개별 후원 금액·내역 | 표시 | **비공개** |
| 받은 축하 메시지 | 표시 | **비공개** |
| 목표 미달 처리·정산 | 표시 | **접근 불가** |

**권한별 공개 원칙**
- 생일자는 자신이 개설한 펀딩의 전체 모금액, 남은 모금액, 후원자별 개별 후원 금액 및 내역을 확인할 수 있다.
- 후원자는 선물 가격과 목표 달성률(%) 및 진행률 바를 확인할 수 있다.
- 후원자는 현재 전체 모금액과 남은 모금액을 기본 화면에서 확인할 수 없다.
- 후원자는 본인이 후원한 금액과 내역만 확인할 수 있다.
- 다른 후원자의 개별 후원 금액과 내역은 공개하지 않는다.
- 후원 금액 초과 시에는 정확한 최대 후원 가능 금액을 예외적으로 안내한다.
- 축하 메시지는 생일자에게만 공개한다.
- 비공개 정책은 화면뿐 아니라 서버 응답 및 접근 권한에도 동일하게 적용한다.

## 5. 주요 화면 이동 흐름

### 5.1 회원가입 및 로그인
- 랜딩 → 회원가입 → 홈
- 랜딩 → 로그인 → 홈

### 5.2 내 펀딩 생성
- 홈 → 내 펀딩 → 펀딩 생성 → 선물 등록 → 펀딩 관리

### 5.3 그룹 생성 및 초대
- 하단 그룹 탭 → 그룹 생성 → 초대 링크 공유 → 그룹 참여

### 5.4 친구 펀딩 참여 및 선물 후원

**친구 펀딩에 처음 참여하는 경우**
1. 홈 → 친구 펀딩
2. "+ 친구 펀딩 참여하기" 버튼 클릭
3. 초대 링크 입력
4. 초대 링크 유효성 확인
5. 펀딩 또는 그룹 정보 확인
6. "참여하기" 버튼 클릭
7. 친구 펀딩 참여 완료
8. 해당 펀딩 상세 화면으로 자동 이동

**친구가 공유한 링크로 접속하는 경우**
1. 친구에게 받은 초대 링크 접속
2. 로그인 확인
3. 초대받은 펀딩 또는 그룹 정보 확인
4. "참여하기" 버튼 클릭
5. 해당 펀딩 상세 화면으로 이동

**선물 후원**
1. 친구 펀딩 → 펀딩 상세
2. 후원할 선물 선택
3. 후원 금액 선택 또는 직접 입력
4. 축하 메시지 작성 또는 추천 문구 선택 (선택사항)
5. 후원하기 버튼 클릭
6. 후원 금액 검증
7. 후원 처리 성공
8. 후원 완료 화면으로 자동 이동
9. 친구 펀딩으로 돌아가기

### 5.5 목표 미달 및 정산
- 내 펀딩 → 종료된 펀딩 → 목표 미달 처리
- 다음 생일로 이월 또는 현재 모금액 인출 선택
- 현재 모금액 인출 선택 시 정산 관리 화면 이동
- 목표 달성 선물은 정상 정산 관리 화면으로 이동
- 이월한 선물은 다음 생일에 펀딩 생성(UI-09) → 이월 선물 불러오기로 다시 연다

### 5.6 기타
- 홈 → 생일 캘린더
- 홈 상단 알림 버튼 → 알림 목록
- 마이페이지 → 프로필 및 취향 수정
- 내 펀딩 → 축하 편지함

## 6. 화면 설계 공통 기준

- 모바일 우선 웹 UI로 설계한다.
- PC 브라우저에서는 주요 앱 영역을 중앙 최대 430px 너비로 배치한다.
- 모바일에서는 화면 너비 100%를 사용한다.
- Y2K 핑크 레트로·Windows 98 스타일 등 세부 컬러·폰트·컴포넌트 기준은 `docs/design/components/base.md`를 따른다.
- 선물·펀딩 정보는 카드 형태로 제공하고 진행률·기간을 명확히 표시한다.
- 생일자는 본인 펀딩의 실제 모금액과 달성률을 모두 확인할 수 있다.
- 후원자는 친구 펀딩의 진행 상태를 달성률(%)과 진행률 바로 확인한다.
- 후원자의 기본 화면에는 현재 전체 모금액과 남은 모금액을 표시하지 않는다.
- 후원 금액 초과 시에만 정확한 최대 후원 가능 금액을 안내한다.
- 후원 금액은 추천 버튼 선택과 직접 입력 방식을 모두 제공한다.
- 축하 메시지 카드는 선택사항이며 추천 문구 자동 입력 기능을 제공한다.
- 후원하기 버튼 클릭 후 처리 성공 시 완료 화면으로 자동 이동한다.
- 친구 펀딩은 초대 링크를 통해 참여하며 접근 권한을 확인한다.
- 화면별 빈 상태, 로딩, 입력 오류, 접근 제한, 완료 상태를 제공한다.
- 결제·송금의 구체적인 구현 방식은 이 화면명세서에서 확정하지 않는다.
