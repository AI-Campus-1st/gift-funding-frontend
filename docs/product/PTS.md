# AI 기반 생일선물 공동 펀딩 플랫폼 기획서

## 1. PTS 정의

### Idea (아이디어)
AI 기반 생일선물 공동 펀딩 플랫폼

### Problem (문제점)
- 생일이나 기념일마다 상대방이 원하는 선물을 고르기 어렵다.
- 선물을 받는 사람은 갖고 싶은 선물이 있어도 가격이 비싸면 상대방에게 부담을 줄까 봐 말하기 어렵다.
- 여러 사람이 함께 선물을 준비하려면 비용을 모으고 관리하는 과정이 번거롭다.
- 공동 선물에 참여할 때 다른 사람과 후원 금액이 비교되는 것이 부담스러울 수 있다.

### Target (타겟)
- 생일이나 기념일에 원하는 선물을 받고 싶은 사람
- 상대방에게 어떤 선물을 줘야 할지 고민하는 사람
- 여러 사람과 함께 선물 비용을 모으고 싶은 사람
- 친구, 가족, 직장 동료 등 가까운 사람들과 선물을 주고받는 사람

### Solution (해결 방안)
생일자가 원하는 선물을 1개 또는 여러 개 등록하고, 초대받은 친구나 지인들이 등록된 선물 중 원하는 선물을 선택하여 자유롭게 금액을 후원하는 비공개 공동 선물 펀딩 플랫폼이다.

AI가 생일자의 취향과 관심사를 바탕으로 선물을 추천하며, 생일자는 그룹별로 펀딩을 생성하고 진행 기간을 설정할 수 있다.

각 선물의 가격이 해당 선물의 목표 금액으로 자동 설정되며, 후원자는 원하는 선물에 부담 없는 금액으로 참여할 수 있다.

펀딩 종료 후에는 모금된 후원금을 본인 명의 계좌로 정산받아 원하는 선물을 자유롭게 구매할 수 있다.

## 2. 주요 기능

### 1. 선물 등록 및 선물별 공동 펀딩
- 생일자가 원하는 선물의 이름, 가격, 이미지, 상품 링크 등을 등록하는 기능
- 원하는 선물을 최소 1개부터 등록할 수 있는 기능
- 선물을 1개만 등록하거나 여러 개 등록할 수 있는 기능
- 선물이 1개라면 해당 선물에 후원하는 기능
- 선물이 여러 개라면 후원자가 원하는 선물을 선택하여 후원하는 기능
- 후원자가 원하는 금액을 직접 입력하여 후원하는 기능
- 각 선물의 가격을 목표 금액으로 설정하고 선물별 모금액과 달성률을 관리하는 기능

### 2. AI 기반 맞춤형 선물 추천
- 생일자의 관심사, 취향, 연령대, 가격대 등을 바탕으로 AI가 선물을 추천하는 기능
- AI가 추천한 선물을 선물 목록에 등록할 수 있는 기능

### 3. 그룹별 펀딩 관리
- 친구, 가족, 직장 동료 등 관계에 따라 그룹을 생성하는 기능
- 그룹마다 서로 다른 선물 목록과 펀딩을 생성하는 기능
- 그룹별로 펀딩 진행 기간을 설정하는 기능
- 그룹별 펀딩을 독립적으로 관리하는 기능

### 4. 비공개 초대형 펀딩
- 생일자가 원하는 사람을 직접 초대하는 기능
- 초대받은 사용자만 펀딩 페이지에 접근하고 후원할 수 있는 기능
- 초대받지 않은 사용자는 선물 목록과 펀딩 내용을 확인할 수 없도록 제한하는 기능
- 그룹별로 참여 권한을 관리하는 기능

### 5. 펀딩 기간 및 선물별 목표 금액 설정
- 생일자가 펀딩 시작일과 종료일을 직접 설정하는 기능
- 등록한 선물의 가격을 해당 선물의 목표 금액으로 자동 설정하는 기능
- 설정한 종료일에 펀딩이 자동으로 마감되는 기능
- 목표 금액을 달성한 선물은 해당 선물의 펀딩이 자동으로 마감되는 기능

### 6. 목표 금액 초과 후원 방지
- 각 선물의 목표 금액 100%까지만 후원할 수 있는 기능
- 남은 목표 금액보다 많은 금액을 입력하면 최대 후원 가능 금액을 안내하는 기능
- 목표 금액을 초과하는 후원을 제한하는 기능
- 목표 금액을 달성한 선물은 추가 후원을 받지 않는 기능

**예시**

에어팟 목표 금액 300,000원 / 현재 모금액 290,000원

후원자가 에어팟에 30,000원을 후원하려고 하면 다음과 같이 안내한다.

"남은 펀딩 가능 금액은 10,000원입니다."

### 7. 목표 금액 미달 시 선택
펀딩 종료 후 선물의 목표 금액을 달성하지 못한 경우, 생일자가 해당 선물에 대해 다음 세 가지 방법 중 하나를 선택하는 기능

1. **다음 생일로 이월:** 모금된 금액을 다음 생일까지 보관
2. **본인 부담금 추가:** 부족한 금액을 생일자가 직접 부담하여 원하는 선물 구매
3. **현금 인출:** 현재까지 모금된 금액을 본인 명의 계좌로 지급받기

### 8. 후원금 정산 및 자유로운 선물 구매
- 펀딩 종료 후 모금된 후원금을 생일자 본인 명의 계좌로 정산하는 기능
- 생일자가 정산받은 금액으로 원하는 쇼핑몰이나 오프라인 매장에서 선물을 직접 구매하는 방식
- 플랫폼에서는 상품 구매 및 배송을 직접 처리하지 않는 방식
- 등록한 선물 외에도 원하는 상품을 자유롭게 구매할 수 있는 방식

### 9. 후원 금액 비공개
- 개인별 후원 금액과 선물별 실제 모금액은 생일자만 확인할 수 있는 기능
- 다른 후원자에게는 선물별 목표 달성률(%)만 표시하는 기능
- 다른 후원자의 후원 금액과 실제 모금액은 공개하지 않는 기능

### 10. 생일 캘린더 및 알림
- 친구의 생일을 등록하고 확인하는 캘린더 기능
- 생일 전날과 당일에 알림을 제공하는 기능
- 생일 알림을 통해 해당 펀딩 페이지로 이동할 수 있는 기능

### 11. 비공개 축하 메시지
- 후원자가 자신의 이름으로 생일자에게 축하 메시지를 작성하는 기능
- 축하 메시지와 작성자 이름은 생일자만 확인할 수 있는 기능
- 다른 후원자나 그룹 구성원은 축하 메시지를 열람할 수 없도록 제한하는 기능
- 축하 메시지에는 후원 금액을 표시하지 않는 기능
- 생일자가 개인 편지함에서 받은 축하 메시지를 확인할 수 있는 기능

## 3. 있으면 좋은 기능

### 1. 펀딩 목표 달성 알림
- 특정 선물이 목표 금액을 달성하면 생일자에게 알림을 제공하는 기능

### 2. 펀딩 종료 전 알림
- 펀딩 종료일이 가까워지면 초대받은 사용자에게 알림을 제공하는 기능

### 3. 펀딩 기록 관리
- 이전에 진행했던 펀딩 내역과 결과를 확인하는 기능

### 4. 축하 편지함 디자인
- 생일자가 받은 축하 메시지를 편지 형태로 모아 볼 수 있는 기능

### 5. 감사 메시지 전송
- **일괄 전송:** 생일자가 후원자 전원에게 동일한 감사 메시지를 한 번에 전송하는 기능
- **개별 전송:** 후원자마다 서로 다른 감사 메시지를 작성하여 전송하는 기능
- 감사 메시지는 해당 후원자만 확인할 수 있도록 비공개로 전달하는 기능

## 6. 차별화 포인트

### 1. 비공개 초대형 그룹 펀딩
초대받은 사람만 펀딩에 참여할 수 있으며, 친구·가족·직장 동료 등 그룹별로 독립적인 펀딩을 운영할 수 있다.

### 2. 선물 선택형 공동 펀딩
생일자가 원하는 선물을 1개 또는 여러 개 등록할 수 있으며, 후원자는 등록된 선물 중 원하는 선물을 선택하여 자유로운 금액으로 후원한다. 선물별로 모금액과 목표 달성률을 관리한다.

### 3. AI 기반 맞춤형 선물 추천
생일자의 취향, 관심사, 연령대, 예산을 반영하여 선물을 추천한다.

### 4. 목표 금액 초과 후원 방지
각 선물 가격의 100%까지만 후원받아 초과 모금을 방지한다.

### 5. 목표 금액 미달 시 선택권
다음 생일로 이월, 본인 부담금 추가, 현금 인출 중 원하는 방법을 선택할 수 있다.

### 6. 후원 금액 비공개
생일자만 후원 금액을 확인하고, 다른 후원자에게는 선물별 달성률만 표시한다.

### 7. 자유로운 선물 구매
생일자가 모금액을 본인 명의 계좌로 정산받아 원하는 곳에서 직접 구매할 수 있다. 등록된 선물 외의 상품도 구매할 수 있다.

### 8. 생일자 전용 비공개 축하 편지함
후원자가 자신의 이름으로 축하 메시지를 남기면 생일자만 확인할 수 있다.
