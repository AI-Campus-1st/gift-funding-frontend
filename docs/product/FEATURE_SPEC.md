
# AI 기반 생일선물 공동 펀딩 플랫폼 기능명세서

## 1. 문서 개요

### 1.1 프로젝트 목적
사용자가 자신의 생일에 받고 싶은 선물을 등록하고, 초대한 친구들이 원하는 금액만큼 공동 후원할 수 있는 플랫폼을 개발한다.

AI 선물 추천을 통해 생일자가 선물을 선택하는 과정을 지원하며, 그룹 관리, 친구 펀딩 참여, 후원 현황 확인, 축하 메시지 전달, 목표 미달 처리 및 정산 기능을 제공한다.

### 1.2 주요 사용자
- 생일자: 자신의 펀딩을 생성하고 선물을 등록하며 모금 현황을 관리하는 사용자
- 후원자: 다른 사람의 펀딩에 참여하여 선물 금액을 후원하는 사용자
- 그룹 관리자: 그룹을 생성하고 초대 링크 및 참여자를 관리하는 사용자

하나의 계정은 펀딩에 따라 생일자와 후원자 역할을 모두 수행할 수 있다.

### 1.3 주요 메뉴
- 홈
- 내 펀딩
- 그룹
- 친구 펀딩
- 마이페이지

### 1.4 공통 운영 원칙
- 그룹 및 펀딩은 초대 기반 비공개 방식으로 운영한다.
- 생일자는 펀딩 이름과 선물을 직접 설정한다.
- 펀딩 이름은 그룹 이름과 별도로 관리한다.
- 선물 가격은 해당 선물의 목표 모금액으로 사용한다.
- 여러 후원자가 하나의 선물에 공동 후원할 수 있다.
- 동일한 후원자가 같은 선물에 여러 번 후원할 수 있다.
- 단, 동일 후원 요청의 중복 처리로 이중 후원이 발생해서는 안 된다.
- 선물별 모금액은 목표 금액을 초과할 수 없다.
- 후원자는 전체 모금액과 남은 모금액을 기본 화면에서 확인할 수 없다.
- 후원 금액 초과 시에는 정확한 최대 후원 가능 금액을 예외적으로 안내한다.
- 축하 메시지는 선택사항이며 후원 과정에서 함께 작성한다.
- 펀딩 종료 후 목표 미달 금액은 다음 생일로 이월하거나 현재 모금액을 인출할 수 있다.
- 선물 구매 및 배송은 플랫폼이 직접 처리하지 않는다.

## 3. 상세 기능명세

### F-01. 회원가입 및 로그인

**기능 목적**
- 사용자가 계정을 생성하고 로그인하여 서비스를 이용할 수 있도록 한다.

**상세 기능**
- 이메일 기반 회원가입
- 이메일 중복 확인
- 비밀번호 입력 및 확인
- 생일 등록
- 로그인 및 로그아웃
- 로그인 상태 유지
- 인증이 필요한 화면 접근 제어

**입력값**
- 이름(필수)
- 이메일(필수)
- 비밀번호(필수)
- 비밀번호 확인(필수)
- 생일(필수)

**출력값**
- 회원가입 성공 또는 실패 결과
- 로그인 성공 또는 실패 결과
- 사용자 인증 정보
- 사용자 기본 프로필

**처리 규칙**
- 모든 필수 항목이 입력되어야 회원가입할 수 있다.
- 이메일은 올바른 이메일 형식이어야 한다.
- 이미 가입된 이메일로 중복 가입할 수 없다.
- 비밀번호와 비밀번호 확인 값이 일치해야 한다.
- 생일은 연도, 월, 일을 선택하는 날짜 선택 UI를 사용한다.
- 존재하지 않는 날짜는 선택할 수 없다.
- 로그인 토큰의 유효기간은 30일이다. '로그인 상태 유지'를 선택하면 브라우저를 닫아도 로그인이 유지되고, 선택하지 않으면 브라우저를 닫을 때 로그아웃된다. <!-- 2026-10-19 확정 -->
- 비밀번호 찾기, 회원 탈퇴, 로그인 실패 횟수 제한은 이번 범위에서 제외한다. 비밀번호 변경은 이후 추가한다. <!-- 2026-10-19 확정 -->
- 비밀번호는 안전한 해시 방식으로 저장한다.
- 로그인 성공 시 홈 화면으로 이동한다.
- 로그인하지 않은 사용자가 보호된 화면에 접근하면 로그인 화면으로 이동한다.
- 초대 링크로 접속한 경우 로그인 후 해당 초대 참여 과정을 이어서 진행한다.

**예외 처리**
- 필수 항목 미입력 시 오류 안내
- 이메일 형식 오류 안내
- 이메일 중복 안내
- 비밀번호 불일치 안내
- 잘못된 생일 입력 안내
- 로그인 정보 불일치 안내
- 인증 만료 시 재로그인 안내

**우선순위:** 필수

### F-02. 프로필 및 선물 취향 관리

**기능 목적**
- 사용자가 자신의 기본 정보와 선물 취향을 관리하여 AI 선물 추천에 활용할 수 있도록 한다.

**상세 기능**
- 프로필 조회 및 수정
- 프로필 사진 등록 및 변경
- 이름 조회 및 수정
- 이메일 조회
- 생일 조회 및 수정
- 관심사 키워드 등록
- 선호 선물 카테고리 설정
- 선호 가격대 설정
- 선물 취향 저장

**입력값**
- 프로필 사진(선택)
- 이름
- 생일
- 관심사 키워드
- 선호 선물 카테고리
- 선호 가격대

**출력값**
- 사용자 프로필
- 저장된 선물 취향
- 수정 결과

**처리 규칙**
- 사용자는 마이페이지에서 본인 정보를 확인할 수 있다.
- 회원가입 시 입력한 생일은 마이페이지에서 수정할 수 있다.
- 생일 변경 시 유효한 날짜인지 확인한다.
- 선물 취향 정보는 AI 선물 추천 시 참고 데이터로 사용한다.
- 관심사 키워드는 최대 10개, 선호 카테고리는 8종, 가격대는 5구간 중에서 고른다. <!-- 2026-10-19 확정 -->
- 프로필 · 선물 이미지는 JPG · PNG · WEBP · GIF 형식, 최대 5MB까지 등록할 수 있다. <!-- 2026-10-19 확정 -->
- 프로필과 취향 정보는 계정별로 저장한다.
- 다른 사용자는 본인의 비공개 프로필 설정을 임의로 수정할 수 없다.

**예외 처리**
- 유효하지 않은 날짜 입력 시 오류 안내
- 허용되지 않은 이미지 형식 업로드 시 오류 안내
- 저장 실패 시 오류 안내
- 인증되지 않은 사용자 접근 제한

**우선순위:** 필수

### F-03. AI 기반 선물 추천

**기능 목적**
- 생일자의 관심사와 예산 등을 분석하여 적절한 생일선물 후보를 추천한다.

**상세 기능**
- 사용자 취향 기반 선물 추천
- 관심사 키워드 입력
- 선호 카테고리 선택
- 예산 범위 입력
- AI 추천 요청
- 추천 결과 목록 표시
- 추천 이유 표시
- 다시 추천받기
- 추천 결과를 선물 등록 과정에 활용

**입력값**
- 사용자 관심사
- 선호 카테고리
- 희망 예산
- 사용자 취향 정보

**출력값**
- 추천 선물 이름
- 추천 이유
- 예상 가격대
- 선물 카테고리

**처리 규칙**
- AI는 입력된 취향 및 예산 정보를 바탕으로 선물을 추천한다.
- 추천 결과는 선물 선택을 돕기 위한 참고 자료로 제공한다.
- 추천된 가격은 실제 판매 가격과 다를 수 있다.
- 추천 결과만으로 선물이 자동 등록되지 않는다.
- 생일자가 실제 상품 가격, 이미지 및 구매 URL을 확인하여 최종 등록한다.
- 추천 결과를 다시 요청할 수 있다.
- AI가 반환한 결과는 화면 표시 전에 필요한 형식 검증을 수행한다.

**예외 처리**
- 추천 요청 실패 시 재시도 안내
- 추천 결과가 없는 경우 안내
- 필수 추천 조건이 부족한 경우 추가 입력 안내
- AI 응답 형식이 올바르지 않은 경우 오류 처리

**우선순위:** 필수

### F-04. 선물 등록 및 수정

**기능 목적**
- 생일자가 펀딩에 사용할 선물을 등록하고 관리할 수 있도록 한다.

**상세 기능**
- 선물 직접 등록
- AI 추천 선물 정보 활용
- 선물 이미지 업로드
- 상품 구매 URL 등록
- 선물 가격 등록
- 선물 정보 수정
- 선물 삭제
- 펀딩별 여러 선물 등록

**입력값**
- 선물 이름(필수)
- 실제 선물 가격(필수)
- 선물 이미지(필수)
- 상품 구매 URL(필수)
- 연결할 펀딩 ID

**출력값**
- 등록된 선물 목록
- 선물 상세 정보
- 등록·수정·삭제 결과

**처리 규칙**
- 선물 등록 시 네 가지 필수 항목을 모두 입력해야 한다.
- 선물 가격은 0원보다 커야 한다.
- 선물 가격(목표 금액)은 최대 5,000만 원(50,000,000원)까지 입력할 수 있다. <!-- 2026-10-19 확정 -->
- 선물 가격을 해당 선물의 목표 모금액으로 설정한다.
- 상품 구매 URL은 올바른 URL 형식이어야 한다.
- 선물 이미지는 허용된 이미지 형식이어야 한다.
- 하나의 펀딩에 여러 개의 선물을 등록할 수 있다.
- 선물 추가는 펀딩이 종료되기 전까지(시작일 전 예정 기간 포함) 언제든 가능하며, 종료된 펀딩에는 추가할 수 없다. <!-- 2026-10-16 확정 -->
- 선물 등록 및 수정 권한은 해당 펀딩의 생일자에게 부여한다.
- 후원이 발생한 선물의 목표 금액 변경이나 삭제는 제한한다.
- 선물 정보는 해당 펀딩에 참여할 권한이 있는 사용자에게만 공개한다.

**예외 처리**
- 필수 항목 미입력 시 오류 안내
- 0원 이하 가격 입력 시 오류 안내
- 잘못된 상품 URL 입력 시 오류 안내
- 이미지 업로드 실패 시 오류 안내
- 후원이 발생한 선물 수정·삭제 시 제한 안내
- 권한이 없는 사용자 수정 요청 거부

**우선순위:** 필수

### F-05. 그룹 생성 및 관리

**기능 목적**
- 사용자가 친구들과 함께 생일 펀딩에 참여할 수 있는 비공개 그룹을 생성하고 관리한다.

**상세 기능**
- 그룹 생성
- 그룹 이름 및 설명 설정
- 내가 만든 그룹 조회
- 참여 중인 그룹 조회
- 그룹 참여자 목록 조회
- 그룹에 연결된 펀딩 목록 조회
- 그룹별 초대 링크 관리
- 그룹 상세 화면 이동
- 그룹 내 친구 펀딩 상세 화면 이동

**입력값**
- 그룹 이름(필수)
- 그룹 설명(선택)
- 그룹 생성자 ID

**출력값**
- 그룹 생성 결과
- 그룹 이름 및 설명
- 그룹 참여자 목록
- 그룹에 연결된 펀딩 목록
- 그룹별 초대 링크

**처리 규칙**
- 그룹 생성자는 해당 그룹의 관리자가 된다.
- 그룹은 비공개로 운영한다.
- 초대 링크를 통해 그룹에 참여할 수 있다.
- 그룹 관리자는 초대 링크를 생성, 복사, 비활성화할 수 있다.
- 그룹 이름과 설명은 그룹을 만든 사람(관리자)만 수정할 수 있다. <!-- 2026-10-19 확정 -->
- 펀딩은 그 그룹을 만든 사람만 열 수 있다. 한 사람이 그룹을 여러 개 만들 수 있고, 그룹마다 펀딩을 열 수 있다. <!-- 2026-10-19 확정 -->
- 그룹에 연결된 펀딩은 접근 권한이 있는 사용자에게만 표시한다.
- 다른 사람의 펀딩은 친구 펀딩 메뉴에서도 확인할 수 있다.
- 동일한 그룹에 중복 가입할 수 없다.
- 그룹 관리 기능은 권한이 있는 사용자에게만 제공한다.
- 그룹 이름과 펀딩 이름은 서로 다른 정보로 관리한다.
- 그룹 삭제 기능은 제공하지 않는다. <!-- 2026-10-16 확정 -->
- 펀딩은 초대받아 참여한 그룹의 펀딩만 열람 · 후원할 수 있다.

**예외 처리**
- 그룹 이름 미입력 시 오류 안내
- 존재하지 않는 그룹 접근 시 오류 안내
- 그룹 접근 권한이 없는 경우 접근 제한
- 중복 그룹 참여 요청 시 기존 참여 상태 안내
- 그룹 생성 또는 수정 실패 시 오류 안내

**우선순위:** 필수

### F-06. 초대 링크 및 친구 펀딩 참여

**기능 목적**
- 사용자가 초대 링크를 통해 다른 사람의 그룹 또는 생일 펀딩에 참여할 수 있도록 한다.
- 참여한 펀딩을 친구 펀딩 메뉴에서 확인할 수 있도록 한다.

**상세 기능**
- 그룹 또는 펀딩 초대 링크 생성
- 초대 링크 복사 및 공유
- 초대 링크 비활성화
- 친구 펀딩 화면에서 초대 링크 직접 입력
- 공유받은 초대 링크 접속
- 초대 링크 유효성 확인
- 로그인 상태 확인
- 참여 대상 정보 확인
- 그룹 또는 펀딩 참여 처리
- 친구 펀딩 목록 자동 반영
- 이미 참여한 그룹 및 펀딩 중복 참여 방지

**입력값**
- 초대 링크 또는 초대 토큰
- 사용자 ID
- 그룹 ID 또는 펀딩 ID

**출력값**
- 초대 링크 검증 결과
- 참여 대상 그룹 또는 펀딩 정보
- 참여 성공 또는 실패 결과
- 친구 펀딩 목록 반영 결과

**처리 규칙**
- 그룹 또는 펀딩 관리 권한이 있는 사용자만 초대 링크를 관리할 수 있다.
- 사용자는 친구 펀딩 메뉴에서 초대 링크를 직접 입력할 수 있다.
- 공유받은 초대 링크를 클릭하여 참여할 수도 있다.
- 로그인하지 않은 사용자는 로그인 후 참여 과정을 계속 진행한다.
- 참여 전 그룹 이름, 펀딩 이름, 생일자 이름 등 대상 정보를 표시한다.
- 사용자가 참여하기 버튼을 클릭하면 참여 권한을 확인한다.
- 참여가 완료되면 해당 펀딩 상세 화면으로 이동한다.
- 펀딩이 지정되지 않은 그룹 초대 링크로 참여하면 그 그룹의 진행 중인 친구 펀딩(시작일이 가장 최근인 것)으로 이동하고, 진행 중인 펀딩이 없으면 그룹 상세 화면으로 이동한다. <!-- 2026-10-19 확정 -->
- 참여한 펀딩은 친구 펀딩 목록에 표시한다.
- 그룹에 연결된 펀딩은 해당 그룹의 접근 권한에 따라 표시한다.
- 이미 참여한 그룹 또는 펀딩은 중복 등록하지 않는다.
- 초대 링크가 유효하더라도 접근 권한이 없는 다른 펀딩은 열람할 수 없다.
- 본인이 개설한 펀딩은 내 펀딩 메뉴에서 관리한다.
- 다른 사람이 개설한 펀딩은 친구 펀딩 메뉴에서 확인한다.
- 특정 펀딩에 연결된 초대 링크는 그 펀딩이 종료되면 만료된다. 그룹 초대 링크는 비활성화하기 전까지 유효하다. <!-- 2026-10-16 확정 -->

**친구 펀딩 참여 흐름**
1. 친구 펀딩 메뉴에 접속한다.
2. "+ 친구 펀딩 참여하기" 버튼을 클릭한다.
3. 초대 링크를 입력한다.
4. 링크 유효성 및 로그인 상태를 확인한다.
5. 그룹 또는 펀딩 정보를 확인한다.
6. "참여하기" 버튼을 클릭한다.
7. 참여 완료 후 해당 펀딩 상세 화면으로 이동한다.
8. 참여한 펀딩이 친구 펀딩 목록에 추가된다.

**예외 처리**
- 유효하지 않은 초대 링크 입력 시 오류 안내
- 비활성화되거나 만료된 링크 사용 시 오류 안내
- 접근 권한이 없는 펀딩 참여 시 접근 제한
- 이미 참여한 펀딩인 경우 기존 펀딩 상세 화면으로 이동
- 참여 처리 실패 시 오류 안내
- 존재하지 않는 그룹 또는 펀딩에 대한 링크 접근 시 오류 안내

**우선순위:** 필수

### F-07. 생일 펀딩 생성 및 관리

**기능 목적**
- 생일자가 그룹을 선택하고 원하는 선물을 등록하여 생일 펀딩을 생성하고 관리한다.

**상세 기능**
- 펀딩 생성
- 펀딩 이름 설정
- 그룹 선택
- 펀딩 시작일 및 종료일 설정
- 선물 등록 및 연결
- 진행 중인 펀딩 조회
- 종료된 펀딩 조회
- 펀딩 상태 관리
- 펀딩 상세 화면 이동

**입력값**
- 펀딩 이름(필수)
- 그룹 ID(필수)
- 펀딩 시작일(필수)
- 펀딩 종료일(필수)
- 선물 목록(최소 1개)

**출력값**
- 생성된 펀딩 정보
- 펀딩 이름 및 기간
- 연결된 그룹 정보
- 등록된 선물 목록
- 펀딩 진행 상태

**처리 규칙**
- 로그인한 사용자만 펀딩을 생성할 수 있다.
- 펀딩은 사용자가 직접 만든 그룹(관리자인 그룹)에만 연결한다. 참여만 한 그룹에는 펀딩을 열 수 없다. 펀딩 하나는 그룹 하나에 연결된다. <!-- 2026-10-19 확정 -->
- 펀딩 이름은 그룹 이름과 별도로 입력한다.
- 펀딩 생성 시 시작일과 종료일을 설정한다.
- 한 사용자가 동시에 진행하거나 예정된 펀딩 개수에는 제한이 없다. <!-- 2026-10-19 확정 -->
- 종료일은 시작일보다 빠를 수 없다.
- 시작일은 오늘 이전 날짜로 정할 수 없다. <!-- 2026-10-16 확정 -->
- 펀딩 기간은 최대 3주(시작일 포함 21일)까지 설정할 수 있다.
- 생일자는 펀딩 이름을 펀딩이 종료되기 전까지 변경할 수 있다. <!-- 2026-10-16 확정 -->
- 펀딩 기간(시작일 · 종료일)은 생성 후 수정할 수 없다.
- 연결 그룹은 펀딩 생성 후 변경할 수 없다. 진행 중에도 초대 링크로 그룹 인원을 추가할 수 있다.
- 최소 한 개 이상의 선물이 등록되어야 펀딩을 생성할 수 있다.
- 펀딩을 생성한 사용자가 해당 펀딩의 생일자가 된다.
- 생일자는 자신의 펀딩을 내 펀딩 메뉴에서 확인한다.
- 다른 참여자는 해당 펀딩을 친구 펀딩 메뉴에서 확인한다.
- 펀딩 기간이 종료되면 추가 후원을 받을 수 없다.
- 종료된 펀딩은 목표 달성 여부에 따라 정산 또는 목표 미달 처리로 연결한다.
- 생일자는 후원이 한 건도 없는 펀딩만 삭제할 수 있다. 이월 금액이 포함된 펀딩은 삭제할 수 없다. <!-- 2026-10-16 확정 -->
- 펀딩을 삭제하면 선물, 그 펀딩 전용 초대 링크, 그 펀딩의 미달 처리 알림을 함께 삭제하고 생일 일정의 펀딩 연결은 해제한다. 생일 알림은 남고 펀딩 연결만 사라진다. <!-- 2026-10-19 확정 -->
- 삭제는 확인 모달을 거치며 복구할 수 없다.
- 펀딩을 만들 때 지난 펀딩에서 이월한 선물을 불러올 수 있다. 불러온 선물은 같은 정보로 다시 열리고 이월 금액이 시작 모금액이 된다. 그룹은 새로 선택할 수 있다.

**예외 처리**
- 펀딩 이름 미입력 시 오류 안내
- 그룹 미선택 시 오류 안내
- 날짜 설정 오류 안내
- 선물 미등록 시 생성 제한
- 그룹 접근 권한이 없는 경우 생성 제한
- 펀딩 생성 실패 시 오류 안내

**우선순위:** 필수

### F-08. 선물 후원 및 후원 금액 선택

**기능 목적**
- 사용자가 친구 펀딩에 등록된 선물을 선택하고 원하는 금액을 후원할 수 있도록 한다.
- 후원 과정에서 선택적으로 축하 메시지를 함께 작성할 수 있도록 한다.

**상세 기능**
- 친구 펀딩의 선물 목록 조회
- 후원할 선물 선택
- 선물 가격 및 상품 구매 링크 확인
- 선물 목표 달성률(%) 및 진행률 바 확인
- 추천 후원 금액 버튼 선택
- 후원 금액 직접 입력
- 축하 메시지 카드 작성(선택)
- 추천 축하 문구 자동 입력
- 후원하기 버튼 클릭
- 후원 처리 성공 시 완료 화면 자동 이동
- 본인 후원 내역 조회

**입력값**
- 후원자 ID
- 펀딩 ID
- 선물 ID
- 후원 금액(필수)
- 축하 메시지(선택)
- 후원 요청 식별 정보

**출력값**
- 선택한 선물 정보
- 목표 달성률(%)
- 후원 처리 결과
- 본인 후원 금액
- 축하 메시지 저장 결과
- 후원 완료 화면

**처리 규칙**
- 사용자는 참여 권한이 있는 친구 펀딩에만 후원할 수 있다.
- 추천 후원 금액 버튼은 5,000원, 10,000원, 30,000원을 제공한다.
- 사용자는 직접 입력을 통해 원하는 후원 금액을 설정할 수 있다.
- 후원 금액은 0원보다 커야 한다.
- 후원 금액은 1원 단위로 입력할 수 있으며 최소 금액은 1원이다. <!-- 2026-10-16 확정 -->
- 생일자는 자신의 펀딩에 후원할 수 없다.
- 후원 취소 · 환불 기능은 이번 범위에서 제외한다 (모의 결제). <!-- 2026-10-19 확정 -->
- 후원 금액은 해당 선물의 남은 모금액을 초과할 수 없다.
- 후원자에게는 선물 목표 금액과 달성률(%)을 표시한다.
- 후원자에게 현재 전체 모금액과 남은 모금액은 기본 화면에서 표시하지 않는다.
- 후원 금액이 남은 모금액을 초과하면 정확한 최대 후원 가능 금액을 안내한다.
- 축하 메시지 작성은 선택사항이다.
- 메시지를 작성하지 않아도 후원할 수 있다.
- 추천 축하 문구를 클릭하면 메시지 입력창에 자동 입력된다.
- 자동 입력된 문구는 사용자가 수정하거나 삭제할 수 있다.
- 후원하기 버튼 클릭 시 후원 금액과 작성한 메시지를 함께 처리한다.
- 메시지가 비어 있으면 메시지 없이 후원을 진행한다.
- 동일 요청의 중복 처리를 방지한다.
- 동일한 사용자가 새로운 후원을 의도적으로 다시 진행하는 것은 허용한다.
- 후원 처리 성공 시 후원 완료 화면으로 자동 이동한다.
- 후원자는 본인의 후원 금액과 내역만 확인할 수 있다.
- 다른 후원자의 개별 후원 금액과 내역은 공개하지 않는다.

**후원 진행 순서**
1. 친구 펀딩에서 후원할 선물을 선택한다.
2. 후원 금액을 추천 버튼으로 선택하거나 직접 입력한다.
3. 축하 메시지를 작성하거나 추천 문구를 선택한다. (선택사항)
4. "{선택한 금액}원 후원하기" 버튼을 클릭한다.
5. 후원 가능 금액 및 펀딩 상태를 검증한다.
6. 후원 금액과 작성한 메시지를 처리한다.
7. 처리 성공 시 후원 완료 화면으로 자동 이동한다.

**예외 처리**
- 후원 금액 미입력 시 후원하기 버튼 비활성화
- 0원 이하 입력 시 오류 안내
- 남은 모금액 초과 시 정확한 최대 후원 가능 금액 안내
- 펀딩 종료 시 후원 불가 안내
- 목표 달성률 100%인 선물은 후원 불가
- 동일 요청 반복 시 중복 처리 방지
- 후원 처리 실패 시 입력 금액과 메시지 유지

**우선순위:** 필수

### F-09. 모금 현황 및 달성률 관리

**기능 목적**
- 선물별 후원 진행 상황을 계산하고 사용자 권한에 맞게 표시한다.

**상세 기능**
- 선물별 목표 금액 조회
- 선물별 전체 모금액 계산
- 선물별 남은 모금액 계산
- 목표 달성률(%) 계산
- 진행률 바 표시
- 펀딩 상태 표시
- 생일자 전용 후원자별 내역 조회
- 후원자 전용 본인 후원 내역 조회

**입력값**
- 펀딩 ID
- 선물 ID
- 후원 데이터
- 조회 사용자 ID

**출력값**
- 선물 목표 금액
- 목표 달성률(%)
- 진행률 바 표시 정보
- 펀딩 진행 상태
- 권한별 모금 정보

**처리 규칙**
- 선물 목표 금액은 등록된 선물의 실제 가격을 사용한다.
- 전체 모금액은 해당 선물에 정상 처리된 후원 금액의 합계로 계산한다.
- 남은 모금액은 목표 금액에서 전체 모금액을 뺀 값으로 계산한다.
- 달성률은 전체 모금액을 목표 금액으로 나누어 계산한다.
- 목표 달성률은 100%를 초과할 수 없다.
- 후원 처리 완료 시 모금 현황을 갱신한다.
- 생일자는 자신의 펀딩에서 목표 금액, 전체 모금액, 남은 모금액, 달성률을 모두 확인할 수 있다.
- 생일자는 후원자 이름과 개별 후원 금액 및 내역을 확인할 수 있다.
- 후원자는 목표 금액, 달성률(%) 및 진행률 바를 확인할 수 있다.
- 후원자는 현재 전체 모금액과 남은 모금액을 기본 화면에서 확인할 수 없다.
- 후원자는 본인의 후원 금액과 내역만 확인할 수 있다.
- 다른 후원자의 개별 후원 금액과 내역은 공개하지 않는다.
- 목표 금액에 도달하면 해당 선물의 후원을 마감한다.

**예외 처리**
- 존재하지 않는 선물 조회 시 오류 안내
- 모금 데이터 조회 실패 시 오류 안내
- 접근 권한이 없는 모금 정보 조회 차단
- 목표 달성 후 추가 후원 요청 거부

**우선순위:** 필수

### F-10. 초과 후원 및 중복 후원 방지

**기능 목적**
- 선물의 목표 금액을 초과하는 후원을 방지하고 동일 요청이 중복 처리되지 않도록 한다.

**상세 기능**
- 후원 가능 금액 검증
- 남은 모금액 계산
- 초과 후원 요청 차단
- 최대 후원 가능 금액 안내
- 동시 후원 요청 처리
- 중복 후원 요청 방지
- 목표 달성 후 후원 마감

**입력값**
- 선물 ID
- 요청 후원 금액
- 후원 요청 식별 정보
- 최신 모금 상태

**출력값**
- 후원 가능 여부
- 후원 성공 또는 실패 결과
- 초과 입력 시 최대 후원 가능 금액
- 중복 요청 처리 결과

**처리 규칙**
- 후원 금액은 0원보다 커야 한다.
- 후원 요청 시 서버에서 최신 모금액을 기준으로 남은 모금액을 계산한다.
- 요청 금액이 남은 모금액 이하인 경우에만 후원을 허용한다.
- 요청 금액이 남은 모금액을 초과하면 후원을 진행하지 않는다.
- 초과 요청 시 정확한 최대 후원 가능 금액을 안내한다.
- 안내 문구:
  "현재 이 선물에는 최대 {후원 가능 금액}원까지 후원할 수 있습니다. 후원 금액을 수정해 주세요."
- 최대 후원 가능 금액 안내는 초과 후원 처리에 한정된 예외이다.
- 일반 후원 화면에서는 현재 전체 모금액과 남은 모금액을 표시하지 않는다.
- 동시에 여러 후원 요청이 발생해도 목표 금액을 초과하지 않도록 처리한다.
- 동일 요청 식별 정보로 반복된 요청은 중복 처리하지 않는다.
- 사용자가 새로운 요청으로 같은 선물에 추가 후원하는 것은 허용한다.
- 목표 금액이 100% 달성되면 추가 후원을 차단한다.
- 펀딩 기간이 종료되면 추가 후원을 차단한다.

**예외 처리**
- 요청 금액이 남은 금액을 초과하면 최대 가능 금액 안내
- 후원 처리 중 목표 금액이 달성된 경우 후원 거부
- 동일 요청이 반복된 경우 중복 처리 방지
- 동시 후원 충돌 발생 시 최신 상태로 재검증
- 종료된 펀딩에 대한 후원 요청 거부

**우선순위:** 필수

### F-11. 목표 미달 처리

**기능 목적**
- 펀딩 종료 후 목표 금액을 달성하지 못한 선물의 모금액을 생일자가 처리할 수 있도록 한다.

**상세 기능**
- 목표 미달 선물 조회
- 미달 금액 및 달성률 확인
- 다음 생일로 이월 선택
- 현재 모금액 인출 선택
- 처리 결과 확인
- 처리 상태 관리

**입력값**
- 펀딩 ID
- 선물 ID
- 생일자 ID
- 목표 미달 처리 방식

**출력값**
- 목표 미달 선물 목록
- 선물별 모금액
- 선택한 처리 방식
- 처리 결과
- 이월 또는 정산 상태

**처리 규칙**
- 목표 미달 처리는 펀딩 종료 후 진행한다.
- 목표 금액을 달성하지 못한 선물만 대상에 포함한다.
- 생일자는 다음 두 가지 방식 중 하나를 선택한다.
  1. 다음 생일로 이월
  2. 현재 모금액 인출
- 다음 생일로 이월을 선택하면 해당 금액을 다음 생일 펀딩에 사용할 수 있도록 관리한다.
- 현재 모금액 인출을 선택하면 정산 관리 기능으로 연결한다.
- 동일한 모금액을 이월과 인출에 중복 사용할 수 없다.
- 처리 완료된 금액은 중복 처리할 수 없다.
- 목표를 달성한 선물은 정상 정산 대상으로 처리한다.
- 생일자는 인출한 금액에 개인 자금을 추가하여 선물을 직접 구매할 수 있다.
- 개인 자금을 플랫폼 안에서 추가 납부하는 별도 기능은 제공하지 않는다.
- 이월한 선물은 다음 생일에 펀딩을 다시 연다. 생일자가 펀딩 생성 화면에서 '이월 선물 불러오기'로 선택하며, 같은 이월 기록은 한 번만 다시 열 수 있다. <!-- 2026-10-16 확정 -->
- 미달 선물의 이월 / 인출 선택 기한은 펀딩 종료 후 7일이며, 7일이 지나도 선택하지 않으면 생일자에게 다시 알림을 보낸다. 알림 이후에도 선택할 수 있다. <!-- 2026-10-16 확정 -->
- 다시 연 선물이 또 목표에 미달하면 목표를 달성할 때까지 다시 이월할 수 있다. <!-- 2026-10-16 확정 -->
- 모금액이 0원인 미달 선물은 처리 대상이 아니며 '종료됨'으로 표시하고 끝난다.

**예외 처리**
- 펀딩 종료 전 처리 요청 제한
- 목표 달성 선물에 대한 미달 처리 요청 제한
- 이미 처리한 금액의 중복 처리 방지
- 권한이 없는 사용자 요청 거부
- 처리 실패 시 오류 안내

**우선순위:** 필수

### F-12. 정산 관리

**기능 목적**
- 생일자가 모금된 금액을 정산받고 선물을 직접 구매할 수 있도록 한다.

**상세 기능**
- 정산 가능 금액 조회
- 정산 대상 선물 조회
- 정산 계좌 정보 입력
- 정산 요청
- 정산 처리 상태 조회
- 정산 이력 조회
- 목표 미달 인출 금액 정산 연동

**입력값**
- 생일자 ID
- 펀딩 ID
- 정산 대상 금액
- 은행
- 계좌번호
- 예금주

**출력값**
- 정산 가능 금액
- 정산 요청 결과
- 정산 상태
- 정산 이력

**처리 규칙**
- 정산 기능은 해당 펀딩의 생일자만 이용할 수 있다.
- 목표를 달성한 선물은 정상 정산 대상으로 처리한다.
- 목표 미달 선물은 현재 모금액 인출을 선택한 경우 정산 대상으로 처리한다.
- 다음 생일로 이월한 금액은 같은 시점에 정산할 수 없다.
- 정산 요청 금액은 정산 가능한 금액을 초과할 수 없다.
- 동일한 정산 대상에 대해 중복 정산을 방지한다.
- 정산 상태(요청 → 처리 중 → 완료 / 실패)는 정산 처리 결과에 따라 시스템이 자동으로 변경한다. <!-- 2026-10-16 확정 -->
- 모의 정산에서는 요청 즉시 '처리 중'이 되고 1분 뒤 '완료'(또는 '실패')가 된다. <!-- 2026-10-19 확정 -->
- 정산 은행은 정해진 9개 은행 중에서 고르고, 계좌번호는 숫자 10~14자리, 예금주는 회원 이름과 같아야 한다. <!-- 2026-10-19 확정 -->
- 정산이 실패하면 실패 이유를 안내하고 계좌 정보를 다시 입력해 재요청할 수 있다. 계좌 정보 오류는 "계좌 정보가 올바르지 않습니다. 계좌 정보를 다시 입력해 주세요.", 은행 오류는 "은행 오류입니다. 다시 입력해 주세요."로 안내한다. <!-- 2026-10-16 확정 -->
- 실패한 정산에 포함된 선물은 다시 정산 대상이 된다.
- 정산 요청 시 계좌 정보를 검증한다.
- 정산 상태 및 이력을 저장한다.
- 정산 완료 후 생일자가 선물을 직접 구매한다.
- 플랫폼은 상품 구매 및 배송을 직접 수행하지 않는다.

**예외 처리**
- 정산 가능 금액이 없는 경우 요청 제한
- 잘못된 계좌 정보 입력 시 오류 안내
- 중복 정산 요청 차단
- 권한이 없는 사용자 요청 거부
- 정산 처리 실패 시 상태 및 오류 안내

**우선순위:** 필수

### F-13. 후원 정보 공개 및 비공개 처리

**기능 목적**
- 생일자와 후원자의 권한에 따라 후원 정보를 구분하여 제공한다.
- 다른 후원자의 개별 후원 정보를 보호한다.

**상세 기능**
- 생일자 전용 모금 상세 정보 제공
- 후원자 전용 달성률 정보 제공
- 후원자 본인 후원 내역 제공
- 다른 후원자 개별 금액 비공개 처리
- 다른 후원자 후원 내역 비공개 처리
- 축하 메시지 비공개 처리
- 권한별 API 응답 구분

**권한별 공개 범위**

| 정보 | 생일자 | 후원자 |
|---|---|---|
| 선물 이름 | 공개 | 공개 |
| 선물 이미지 | 공개 | 공개 |
| 선물 가격·목표 금액 | 공개 | 공개 |
| 상품 구매 URL | 공개 | 공개 |
| 현재 전체 모금액 | 공개 | 비공개 |
| 남은 모금액 | 공개 | 비공개 |
| 목표 달성률(%) | 공개 | 공개 |
| 진행률 바 | 공개 | 공개 |
| 본인 후원 금액 | 해당 시 공개 | 공개 |
| 다른 후원자 개별 후원 금액 | 공개 | 비공개 |
| 다른 후원자 후원 내역 | 공개 | 비공개 |
| 후원자 이름 및 내역 | 공개 | 타인 정보 비공개 |
| 축하 메시지 | 수신 메시지 공개 | 타인 메시지 비공개 |
| 정산 정보 | 공개 | 접근 불가 |

**처리 규칙**
- 생일자는 본인이 개설한 펀딩의 전체 모금액과 남은 모금액을 확인할 수 있다.
- 생일자는 후원자 이름, 개별 후원 금액, 후원 일자 및 내역을 확인할 수 있다.
- 후원자는 선물 목표 금액과 달성률(%) 및 진행률 바를 확인할 수 있다.
- 후원자는 현재 전체 모금액과 남은 모금액을 기본 화면에서 확인할 수 없다.
- 후원자는 본인의 후원 금액과 내역만 확인할 수 있다.
- 후원자는 다른 후원자의 개별 후원 금액과 내역을 조회할 수 없다.
- 후원 금액이 남은 모금액을 초과한 경우 정확한 최대 후원 가능 금액을 예외적으로 안내한다.
- 최대 후원 가능 금액은 초과 후원 오류 처리 시에만 제공한다.
- 축하 메시지는 해당 펀딩의 생일자만 열람할 수 있다.
- 생일자 전용 정산 정보는 후원자에게 제공하지 않는다.
- 비공개 정보는 화면에서만 숨기는 것이 아니라 서버 응답에서도 제외한다.
- 모든 상세 정보 조회 시 서버에서 사용자 권한을 확인한다.

**예외 처리**
- 권한이 없는 상세 정보 조회 요청 거부
- 다른 후원자의 개별 후원 내역 요청 거부
- 축하 메시지 무단 조회 요청 거부
- 정산 정보 무단 조회 요청 거부
- 인증되지 않은 사용자 접근 제한

**우선순위:** 필수

### F-14. 비공개 축하 메시지 카드

**기능 목적**
- 후원자가 생일자에게 축하 메시지를 전달할 수 있도록 한다.
- 직접 작성이 번거로운 사용자를 위해 추천 축하 문구를 제공한다.

**상세 기능**
- 후원 화면에 축하 메시지 카드 표시
- 축하 메시지 직접 입력
- 추천 축하 문구 버튼 제공
- 추천 문구 클릭 시 자동 입력
- 자동 입력된 메시지 수정 및 삭제
- 메시지 미리보기
- 메시지 없이 후원 진행
- 후원 완료 시 작성한 메시지 저장
- 생일자 전용 축하 편지함 제공

**입력값**
- 후원자 ID
- 펀딩 ID
- 축하 메시지(선택)

**출력값**
- 작성자 실명
- 축하 메시지 내용
- 메시지 작성일
- 생일자 전용 메시지 조회 결과

**추천 축하 문구**
- "생일 축하해! 🎂"
- "태어나줘서 고마워 💗"
- "오늘 하루 행복하게 보내! 🎉"
- "항상 좋은 일만 가득하길 ✨"

**처리 규칙**
- 축하 메시지 작성은 필수가 아니다.
- 후원자는 메시지를 작성하지 않고 후원을 완료할 수 있다.
- 추천 문구 버튼 클릭 시 해당 문구가 입력창에 자동 입력된다.
- 다른 추천 문구를 클릭하면 기존 문구가 선택한 문구로 변경된다.
- 사용자는 자동 입력된 문구를 자유롭게 수정하거나 삭제할 수 있다.
- 추천 문구를 사용하지 않고 직접 작성할 수 있다.
- 메시지는 후원하기 버튼 클릭 시 후원 정보와 함께 저장한다.
- 메시지가 없는 경우 별도 메시지 데이터를 생성하지 않는다.
- 작성자 이름은 회원가입 시 등록한 실명을 사용한다.
- 익명 또는 별명 선택 기능은 제공하지 않는다.
- 메시지에 후원 금액을 자동 표시하지 않는다.
- 축하 메시지는 해당 펀딩의 생일자만 열람할 수 있다.
- 다른 후원자는 메시지 내용을 열람할 수 없다.
- 생일자는 축하 편지함에서 받은 메시지를 확인할 수 있다.
- 후원 완료 후 별도의 메시지 작성 화면으로 이동하지 않는다.

**예외 처리**
- 메시지를 입력하지 않은 경우 정상 후원 진행
- 후원 처리 실패 시 작성 중인 메시지 유지
- 접근 권한이 없는 메시지 조회 시 접근 거부
- 메시지 저장 실패 시 후원 처리와의 일관성 유지

**우선순위:** 필수

### F-15. 생일 캘린더

**기능 목적**
- 사용자가 친구들의 생일을 등록하고 확인하여 생일 펀딩에 참여할 수 있도록 돕는다.

**상세 기능**
- 월별 생일 캘린더 조회
- 친구 생일 등록
- 친구 생일 수정
- 친구 생일 삭제
- 생일 일정 상세 조회
- 생일 일정과 펀딩 연결
- 연결된 펀딩으로 이동

**입력값**
- 친구 이름(필수)
- 생일(필수)
- 연결할 펀딩 ID(선택)

**출력값**
- 월별 생일 일정
- 친구 이름 및 생일
- 연결된 펀딩 정보

**처리 규칙**
- 사용자는 캘린더에서 월별 생일 일정을 확인할 수 있다.
- 연도와 월을 이동하여 생일을 조회할 수 있다.
- 사용자는 친구 생일을 직접 등록, 수정, 삭제할 수 있다.
- 생일 입력 시 유효한 날짜인지 확인한다.
- 2월 29일생은 평년(2월 29일이 없는 해)에 2월 28일을 생일로 표시한다. <!-- 2026-10-19 확정 -->
- 생일 일정에 접근 권한이 있는 펀딩을 연결할 수 있다.
- 연결된 펀딩을 클릭하면 해당 펀딩 상세 화면으로 이동한다.
- 접근 권한이 없는 펀딩은 연결되어 있어도 상세 내용을 열람할 수 없다.
- 생일 하루 전과 당일 알림 기능에 생일 일정 데이터를 활용한다.
- 생일 일정을 삭제하면 그 일정으로 생성된 알림도 함께 삭제한다. <!-- 2026-10-16 확정 -->

**예외 처리**
- 친구 이름 미입력 시 오류 안내
- 유효하지 않은 생일 입력 시 오류 안내
- 존재하지 않는 일정 조회 시 오류 안내
- 접근 권한이 없는 연결 펀딩 열람 제한

**우선순위:** 필수

### F-16. 알림 기능

**기능 목적**
- 사용자가 친구의 생일과 관련 일정을 놓치지 않도록 알림을 제공한다.

**상세 기능**
- 생일 하루 전 알림
- 생일 당일 알림
- 알림 목록 조회
- 읽지 않은 알림 표시
- 알림 읽음 처리
- 알림 클릭 시 관련 화면 이동

**입력값**
- 사용자 ID
- 생일 일정
- 알림 생성 기준일
- 알림 읽음 상태

**출력값**
- 알림 제목
- 알림 내용
- 알림 생성일
- 읽음 상태
- 관련 화면 이동 정보

**처리 규칙**
- 등록된 생일 일정에 따라 생일 하루 전과 당일 알림을 생성한다.
- 2월 29일생은 평년에 2월 28일을 기준으로 알림을 보낸다. 알림은 매일 0시에 자동 생성한다(개발 단계에서는 알림 목록을 볼 때 생성). <!-- 2026-10-19 확정 -->
- 목표 미달 선물을 펀딩 종료 후 7일 안에 처리하지 않으면 생일자에게 미달 처리 알림을 생성한다. 이 알림은 펀딩마다 한 번만 보낸다. <!-- 2026-10-16 확정 -->
- 알림은 서비스 내부에서 확인할 수 있도록 제공한다.
- 읽지 않은 알림이 있으면 알림 아이콘에 표시한다.
- 사용자가 알림을 확인하면 읽음 상태로 변경한다.
- 알림을 클릭하면 관련 생일 일정 또는 접근 가능한 펀딩 화면으로 이동한다.
- 동일 일정에 대해 같은 날짜와 유형의 알림이 중복 생성되지 않도록 한다.
- 접근 권한이 없는 펀딩의 비공개 정보는 알림에 포함하지 않는다.

**예외 처리**
- 알림 생성 실패 시 오류 기록
- 존재하지 않는 연결 화면 이동 시 오류 안내
- 권한이 없는 펀딩 연결 시 접근 제한
- 알림 목록 조회 실패 시 오류 안내

**우선순위:** 필수

## 4. 공통 데이터 및 권한 규칙

### 4.1 사용자 역할
- 하나의 사용자는 여러 그룹에 참여할 수 있다.
- 하나의 사용자는 자신의 펀딩을 생성할 수 있다.
- 하나의 사용자는 다른 사람의 펀딩에 후원할 수 있다.
- 동일한 사용자는 펀딩마다 생일자 또는 후원자 역할을 가질 수 있다.
- 그룹 관리자 권한과 펀딩 생일자 권한은 구분한다.

### 4.2 펀딩 접근 권한
- 펀딩은 초대받거나 참여 권한을 가진 사용자만 조회할 수 있다.
- 본인 펀딩은 내 펀딩 메뉴에 표시한다.
- 다른 사람의 펀딩은 친구 펀딩 메뉴에 표시한다.
- 그룹 참여만으로 모든 비공개 펀딩에 무조건 접근할 수 있는 것은 아니다.
- 펀딩은 연결된 그룹의 참여자에게 공개한다. 다른 그룹에 연결된 펀딩은 볼 수 없다. <!-- 2026-10-19 확정 -->
- 서버에서 그룹 및 펀딩별 접근 권한을 검증한다.

### 4.3 모금액 및 달성률
- 선물 가격 = 선물 목표 모금액
- 현재 모금액 = 정상 처리된 후원 금액 합계
- 남은 모금액 = 목표 모금액 - 현재 모금액
- 목표 달성률(%) = 현재 모금액 / 목표 모금액 × 100
- 목표 달성률은 최대 100%로 제한한다.
- 목표 달성 후 추가 후원은 불가능하다.
- 펀딩 종료 후 추가 후원은 불가능하다.

### 4.4 후원 정보 공개 범위
- 생일자는 실제 모금액, 남은 모금액, 후원자별 이름과 금액 및 내역을 확인할 수 있다.
- 후원자는 선물 목표 금액과 달성률 및 진행률 바를 확인할 수 있다.
- 후원자는 현재 전체 모금액과 남은 모금액을 기본 화면에서 확인할 수 없다.
- 후원자는 본인의 후원 금액과 내역만 확인할 수 있다.
- 다른 후원자의 개별 후원 금액 및 내역은 비공개이다.
- 후원 금액 초과 시에는 최대 후원 가능 금액을 예외적으로 안내한다.
- 목표 금액과 달성률이 공개되므로 전체 모금액을 대략 추정할 가능성은 있으나, 실제 모금액 자체를 직접 제공하지 않는 정책을 적용한다.

### 4.5 후원 처리 안정성
- 후원 가능 여부는 서버에서 최종 검증한다.
- 동시 후원 요청으로 목표 금액을 초과하지 않도록 처리한다.
- 동일 후원 요청은 중복 처리하지 않는다.
- 새로운 요청으로 같은 선물에 여러 번 후원하는 것은 허용한다.
- 후원과 축하 메시지 저장은 일관성 있게 처리한다.
- 처리 실패 시 잘못된 후원 완료 상태를 표시하지 않는다.

### 4.6 선물 구매 및 정산
- 플랫폼은 선물 구매 링크를 제공한다.
- 플랫폼이 선물을 직접 구매하거나 배송하지 않는다.
- 생일자가 정산받은 금액으로 직접 상품을 구매한다.
- 목표 미달 선물은 다음 생일 이월 또는 현재 모금액 인출 중 하나를 선택한다.
- 부족한 금액을 플랫폼 내에서 별도로 충전하는 기능은 제공하지 않는다.

## 5. 주요 사용자 흐름

### 5.1 생일자 펀딩 생성
1. 회원가입 또는 로그인
2. 그룹 생성 또는 기존 그룹 선택
3. 펀딩 이름 및 기간 설정
4. AI 선물 추천 또는 선물 직접 등록
5. 선물 실제 가격, 이미지, 구매 URL 등록
6. 펀딩 생성
7. 친구에게 초대 링크 공유
8. 내 펀딩에서 모금 현황 확인
9. 종료 후 정산 또는 목표 미달 처리

### 5.2 친구 펀딩 참여
1. 친구 펀딩 메뉴 접속
2. "+ 친구 펀딩 참여하기" 클릭
3. 초대 링크 입력
4. 링크 유효성 확인
5. 그룹 또는 펀딩 정보 확인
6. "참여하기" 클릭
7. 친구 펀딩 목록에 추가
8. 펀딩 상세 화면 이동

### 5.3 초대 링크 직접 접속
1. 친구가 공유한 초대 링크 접속
2. 로그인 상태 확인
3. 로그인하지 않았다면 로그인
4. 초대 링크 유효성 확인
5. 참여 대상 정보 확인
6. "참여하기" 클릭
7. 해당 펀딩 상세 화면 이동

### 5.4 선물 후원
1. 친구 펀딩 상세 화면 접속
2. 후원할 선물 선택
3. 추천 금액 버튼 선택 또는 직접 입력
4. 축하 메시지 작성 또는 추천 문구 선택(선택사항)
5. "{선택한 금액}원 후원하기" 클릭
6. 서버에서 후원 가능 금액 및 상태 검증
7. 후원 및 메시지 처리
8. 후원 완료 화면 자동 이동
9. 친구 펀딩으로 돌아가기

### 5.5 후원 금액 초과
1. 후원자가 금액 입력
2. 서버에서 최신 남은 모금액 확인
3. 입력 금액이 남은 모금액을 초과하면 요청 거부
4. 정확한 최대 후원 가능 금액 안내
5. 후원자가 금액 수정
6. 수정된 금액으로 다시 후원 요청

### 5.6 펀딩 종료 및 정산
1. 펀딩 기간 종료
2. 선물별 목표 달성 여부 확인
3. 목표 달성 선물은 정상 정산 진행
4. 목표 미달 선물은 이월 또는 인출 선택
5. 인출 선택 시 정산 관리로 이동
6. 생일자가 정산받은 금액으로 선물 직접 구매
